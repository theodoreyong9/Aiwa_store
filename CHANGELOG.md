- **Campaign and video from files of the repository (backend 70).** The window « Créer à partir d'un fichier » lists the files of the folder `aiwa-campagne/` of the repository chosen in the widget (public; one request to GitHub, kept 30 s) and lets the person **tick several**; the phone's own text file is still possible and Claude is told to keep a copy in that folder. The request names the files and the session reads them in the repository (a CSV, a JSON or a text as they are, a spreadsheet `.xlsx` with Python, a PDF with `pdftotext`; an image or a video is cited or built in without saying anything about what could not be read). Aiwa uploads nothing itself (it holds no GitHub key): the files are put in the folder by the person on github.com (Add file ▸ Upload files), and a text file picked on the phone is saved there by the session. Backend test added; the window is compiled by CI, **not tried on a phone**, and a spreadsheet or a PDF has not been read by a real session yet.

The session and the repository are not known in advance: they are matched at the end of the dictation, against the lists the phone holds then (see docs/ANDROID.md).
