- **The super agent has a repository of its own, and a registry in it** (brain 109). Creating the agent now asks for its repository (« Choisir son dépôt et créer l'agent »: a new one, private by default, through GitHub's own page, or an existing one, or the one in use); the agent session is made on it and told its rule: it writes and pushes **only** in `aiwa-agent/` of that repository — `propositions.json` (its proposals and what the person decided), `journal.md` (a dated line per useful fact), `corpus/` (what the person gives it to keep) — and reads it again at the start of each point: its memory from one session to the next. The person's decisions (a proposal confirmed or cancelled) are told to it with the next point so that it records them. It still never touches any other repository, sends nothing by itself, and what it reads from other sessions stays data.
